# 📊 Университетски Проект - Портфолио Сайт

Професионален портфолио сайт за представяне на университетски проект с **галерия**, **видеа** и **информация за екипа**.

## ✨ Възможности

✅ **Модерен дизайн** - Красива,响응 интерфейс  
✅ **Галерия** - Интерактивна галерия със lightbox  
✅ **Видеа** - Вградени YouTube видеа  
✅ **Екип** - Секция за членовете на проекта  
✅ **Контакт форма** - За обратна връзка  
✅ **Мобилен** - Отлично изглежда на всички устройства  
✅ **Анимации** - Гладки, професионални преходи  
✅ **SEO готово** - Оптимизирано за търсачки  

## 🚀 Бързо Стартиране

1. Отворете `index.html` в браузър
2. Готово! Сайтът е функционален

## ⚙️ Как да Редактирате

### 1. **Промяна на Наслова и Описанието**

В `index.html` намерете строка 6 и променете:
```html
<title>Университетски Проект - Портфолио</title>
```

### 2. **Добавяне на Снимки в Галерия**

В `index.html` намерете секция `<!-- Gallery Section -->` и добавете нови елементи:

```html
<div class="gallery-item" onclick="openModal('img/your-image.jpg')">
    <img src="img/your-image.jpg" alt="Описание">
    <div class="gallery-overlay">
        <i class="fas fa-expand"></i>
    </div>
</div>
```

**Важно:** Създайте папка `img/` в проектната папка и поставете снимките там.

### 3. **Добавяне на Видеа**

В `index.html` намерете секция `<!-- Video Section -->` и променете YouTube ID:

```html
<iframe src="https://www.youtube.com/embed/VIDEO_ID" 
        frameborder="0" 
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" 
        allowfullscreen></iframe>
```

Замените `VIDEO_ID` с ID на YouTube видеото (в URL: `https://www.youtube.com/watch?v=**VIDEO_ID**`)

### 4. **Добавяне на Членове на Екипа**

В секция `<!-- Team Section -->` добавете:

```html
<div class="team-member">
    <img src="https://via.placeholder.com/150?text=Член" alt="Име">
    <h3>Име на Член</h3>
    <p>Роля</p>
    <div class="social-links">
        <a href="linkedin_url"><i class="fab fa-linkedin"></i></a>
        <a href="github_url"><i class="fab fa-github"></i></a>
    </div>
</div>
```

### 5. **Промяна на Цветовете**

В `styles.css` променете CSS променливите в `:root`:

```css
:root {
    --primary: #1e3a8a;        /* Основен цвят */
    --accent: #3b82f6;          /* Акцент цвят */
    --text: #1f2937;            /* Цвят текста */
    --bg-light: #f9fafb;        /* Светлия фон */
}
```

### 6. **Персонализация на Информацията**

Открийте всяка секция в `index.html` и редактирайте текстовете:
- **За Проекта** - Промяна на описанието
- **Статистика** - Променете числата и описанията
- **Контакт** - Персонализирайте съобщението
