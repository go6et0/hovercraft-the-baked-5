## 🌐 ВАРИАНТ 1: GitHub Pages (Препоръчано)

### Стъпка 1: Създайте GitHub Repository
1. Отидете на https://github.com/new
2. Име: `университетски-проект` или `project-portfolio`
3. Изберете **Public**
4. Натиснете **Create repository**

### Стъпка 2: Качете файловете
```bash
cd c:\Users\user\Documents\project

# Инициализирайте Git репозиториум
git init
git add .
git commit -m "Начален комит - Портфолио сайт"

# Качете на GitHub
git remote add origin https://github.com/ВАШ_USERNAME/университетски-проект.git
git branch -M main
git push -u origin main
```

### Стъпка 3: Активирайте GitHub Pages
1. Отидете в **Settings** на репото
2. Левия меню → **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main**
5. Folder: **/ (root)**
6. Натиснете **Save**

✅ **Готово!** Сайтът е на: `https://ВАШ_USERNAME.github.io/университетски-проект`

---

## 🌐 ВАРИАНТ 2: Netlify (Най-Лесно)

### Стъпка 1: Отворете https://netlify.com

### Стъпка 2: Drag & Drop
1. Натиснете **Add new site** → **Deploy manually**
2. Преместете цялата папка `project` тук
3. Чакайте 30 секунди...

✅ **Готово!** Сайтът е активен на случаен URL

### (Опционално) Персонализирайте домена
1. Натиснете на Site settings
2. Change site name
3. Изберете име, напр. `мой-проект-2024`

✅ Сайтът е на: `мой-проект-2024.netlify.app`

---

## 🌐 ВАРИАНТ 3: Vercel

### Стъпка 1: Свържете GitHub
1. Отидете на https://vercel.com
2. Натиснете **New Project**
3. Выберите репото
4. Натиснете **Import**

### Стъпка 2: Конфигурация
- Root Directory: `.` (корен)
- Build Command: оставете празно
- Output Directory: оставете празно

✅ **Готово!** Развертането е автоматично

## ❓ Проблеми?

### Снимките не се показват
- Проверете дали пътят е правилен в `index.html`
- Пътят трябва да е: `img/име-на-снимка.jpg`

### Видеата не работят
- Проверете YouTube ID в iframe src
- Формат: `https://www.youtube.com/embed/VIDEO_ID`

### Сайтът е бавен
- Оптимизирайте снимките (под 500KB)
- Используйте JPG вместо PNG ако е възможно

### Стилове не се прилагат
- Почистете кеша на браузър (Ctrl+Shift+Delete)
- Проверете дали `styles.css` е в същата папка като `index.html`
